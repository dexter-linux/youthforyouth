# Area photographs

Put your JPG, JPEG, PNG, WEBP or GIF photographs in this folder.

The GitHub Actions workflow scans this folder whenever you push to the `main` branch and creates `manifest.json`. The Gallery page and the homepage area preview then load every listed image automatically.

You can optionally add a matching text file named `photo-name.txt` beside an image to provide a caption, for example:

- `market-day.jpg`
- `market-day.txt` containing `Market day in Ol Moran`

Use descriptive filenames and only publish photographs you have permission to use. Avoid uploading private or sensitive personal information.
